# 3-Laptop Cluster Homelab & 3D Prototypes

Interactive 3D prototypes, server architectures, and parametric CAD designs for turning 3 old laptops into an automated, fault-tolerant home server.

## Live Interactive Viewer
👉 **[Open Live 3D Interactive Webpage](https://faizsetiawan12.github.io/homelab-cluster/)**

## Features
- **Interactive 3D Enclosure Prototypes**: Switch between Vertical Toaster Stand, 3-Bay Blade Rack with 120mm fan shroud, and Under-Desk brackets with full 360° mouse/touch rotation and exploded view.
- **Quorum Failure Simulator**: Interactive 3-node voting simulator testing Proxmox VE high availability failover.
- **Hardware & Power Calculator**: Real-time idle power, annual electricity cost, and RAM/storage aggregator.
- **Parametric 3D CAD Files**: Ready-to-print OpenSCAD files (`.scad`) tailored for 3D printing in PETG/ABS.

## 3D CAD Models
- `vertical_cluster_stand.scad`: Desk vertical toaster stand with 25mm convection cooling slots and cable tunnels.
- `blade_rack_fan_mount.scad`: Modular stackable blade server trays with 120mm USB fan mount and 5-port switch bay.
- `wall_underdesk_mount.scad`: Universal space-saving under-desk / wall bracket pairs.
