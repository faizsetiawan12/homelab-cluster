Server Architecture Blueprints

3 laptops is the ideal number for homelabs because of Quorum voting and role separation.

Proxmox VE HA Cluster

High-Availability with 3-Node Quorum

ARCH 01
Live Quorum Simulator 3 / 3 Votes (100%)
CLUSTER HEALTHY: Quorum Met (≥ 51%)
Cluster

Multiple computers joined together to act as one single powerful system.

Node

A single computer inside the cluster (here, one of your laptops).

Quorum

Minimum votes needed to make decisions. 3 nodes need 2 votes (>50%). If 1 laptop dies, the other 2 keep all apps running.

High Availability (HA)

If Laptop A crashes, Laptop B or C automatically restarts its apps within seconds.

Best For: Self-hosting critical services that must never go down (Home Assistant, password managers, DNS).

Tiered Role Separation

Gateway + Storage (NAS) + Compute

ARCH 02
Gateway

The front door. Inspects all web traffic, blocks ads (Pi-hole), and secures connections (WireGuard VPN).

NAS (Storage)

Network Attached Storage. A server dedicated to holding photos, movies, and hard drive backups.

Reverse Proxy

A traffic cop that guides web requests to the exact app on the right laptop without exposing your private network.

Best For: When your 3 laptops have very different specs (e.g. 1 weak laptop for network, 1 with big SSD for storage, 1 fast CPU for apps).

Lightweight k3s Cluster

Modern Containerized Cloud-Native Lab

ARCH 03
Container

An isolated lightweight box holding an app and everything it needs to run.

k3s

A lightweight, low-memory version of Kubernetes made for home servers and edge hardware.

Control Plane

The leader server. Decides which laptop will run each app based on available RAM and CPU.

Best For: Anyone wanting to learn real-world cloud engineering skills (DevOps, Kubernetes).

2-Node Prod + 1 Sandbox

Safe Experimentation & Disaster Recovery

ARCH 04
Production (Prod)

The live system your family or home depends on every day. Kept stable and untouchable.

Sandbox

An isolated test machine where you can test scripts, break things, and reinstall without affecting the house.

Best For: Tinkering without getting yelled at by family when internet or smart lights go down.

Laptop-to-Server Hardware Hacks

Laptops have built-in battery backups and screens, but need special setup to run safely 24/7.

🔋

1. Battery Swelling Prevention

Keeping laptop batteries at 100% on charge 24/7 causes chemical stress and dangerous battery swelling ("spicy pillows").

  • A
    Set BIOS Charge Threshold: Check BIOS for "Battery Health Charge" or "Conservation Mode". Cap maximum charge to 60% or 80%.
  • B
    Remove Battery (If supported): If laptop boots directly from AC adapter with battery removed, pull the battery out completely.
  • C
    Free Built-in UPS:
    A healthy capped battery gives you 30-60 minutes of free power protection during blackout outages!
❄️

2. Thermal & Lid Management

Laptops exhaust heat through keyboard surfaces. Closing the lid traps heat against the LCD screen and triggers sleep mode.

  • A
    Never Close Lid Completely: Leave lid ajar 15-20° or remove screen ribbon if comfortable.
  • B
    Disable Linux Lid Sleep: Edit /etc/systemd/logind.conf:
    HandleLidSwitch=ignore HandleLidSwitchExternalPower=ignore
  • C
    Turn Off Screen Backlight: Saves 5-8 Watts per laptop. In terminal:
    setterm --blank 1 --powerdown 1
🔌

3. Networking & Auto-Power-On

Make the laptops start back up automatically after a prolonged blackout and maintain rock-solid connection.

  • A
    BIOS "AC Back / Auto Power-On": Set "Restore on AC Power Loss" to Power On so the laptops boot immediately when electricity returns.
  • B
    Hardwire with Ethernet: Never run server clusters over Wi-Fi. If laptop lacks RJ45 port, buy a $12 USB 3.0-to-Gigabit Ethernet dongle.
  • C
    Connect to a Cheap 5-Port Switch: Link all 3 laptops + your router to a $15 unmanaged gigabit switch for lightning-fast internal sync.
